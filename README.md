# Earth Engine code

Google Earth Engine scripts by Ahmad Ammar, grouped by topic: about 40,000 lines written over several years, for research, teaching and learning.

| Folder | Topic |
|---|---|
| `scripts/gedi-mangroves` | GEDI LiDAR, canopy height and biomass, Indus Delta |
| `scripts/monsoon` | South Asian monsoon, rainfall, temperature, sea surface temperature |
| `scripts/third-pole` | Snow, basins and mountain ranges across the Third Pole |
| `scripts/air-quality` | Air pollution and machine learning |
| `scripts/land-cover` | Land cover and vegetation |
| `scripts/sar` | Sentinel-1 radar, floods and ships |
| `scripts/urban` | Urban growth, night-time lights, land surface temperature |
| `scripts/timelapse` | Time-lapse animations |
| `scripts/water-quality` | Water quality |
| `scripts/preprocessing` | Harmonisation, indices and normalisation |
| `scripts/phd-building-energy` | Earth Engine steps of doctoral work on building energy |
| `scripts/learning`, `scripts/general` | Exercises and other scripts |

`MANIFEST.csv` maps each file to its original path. Slashes in original paths became `__`.

## Using a script

Paste it into the [Earth Engine Code Editor](https://code.earthengine.google.com). Many are working versions, kept as written, and have not been tidied or re-tested. Some read private assets, which you would replace with your own data. Some import libraries by other authors through `require()`, including `users/fitoprincipe/geetools`, `users/dmlmont/spectral`, `users/gena/packages` and `users/elacerda/geet`.
